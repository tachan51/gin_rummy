# ジンラミー vs 最強AI

ブラウザで遊べるジンラミー（Gin Rummy）。ビルド不要の静的サイト（HTML/CSS/JavaScript）で、GitHub Pages で公開できます。

## 遊び方

- 山札か捨て札をタップして1枚引き、手札のカードをタップして選択 → もう一度タップ（または「捨てる」）で捨てます。
- 捨てた後のデッドウッドが10以下なら「ノック」、0なら「ジン！」。
- 「ヒント」で最強AIのおすすめ手が見られます。設定で AI の強さ（最強 / ふつう / よわい）・目標点・AIの手札表示（練習用）を変更できます。
- ルールは画面右上の「ルール」から確認できます（ノック・ジン25点・ビッグジン31点・アンダーカット25点・付け札あり・山札残り2枚で流局・100点先取＋ゲーム/ボックスボーナス）。

## AI（最強）のしくみ — `web/js/ai.js`

1. **カードカウンティング**: 捨て札・自分の手札・相手が捨て札から拾ったカードを全て記憶し、まだ見えていないカードを特定。
2. **相手の手札推定**: 相手が拾ったカードの周辺は「持っていそう」、捨てた・見送ったカードの周辺は「持っていなさそう」として、未知カードごとに相手が持っている確率を推定。
3. **手札評価**: 最小デッドウッド −（次に引くカードによるデッドウッド減少の期待値 × 重み）。ノック圏・ジン到達にはボーナス。メルドの組み方は全探索で常に最適。
4. **ドロー判断**: 「捨て札を取った場合」と「山札から引いた場合（未知カード全てについての期待値）」を1手先読みで比較。
5. **捨て札判断**: 評価値 ＋ 危険度（そのカードで相手がセット/ランを作れる確率）のペナルティ。
6. **ノック判断**: 相手の手札を、引いた回数に応じて「上達させながら」数十通りサンプリングし、付け札込みでアンダーカットされる確率と期待得点を計算して判断。

パラメータはAI同士の自己対戦で調整しています（`tools/selfplay.mjs`）。参考値（各対戦 1,000〜3,000 ハンド、席を入れ替えて同じ配札で対戦）:

| 対戦 | 1ハンドあたりの平均得点差 |
| --- | --- |
| 最強 vs ふつう（デッドウッド最小化の貪欲AI） | 約 +4 点 |
| 最強 vs よわい | 約 +19 点 |
| 最強 vs 「必ず即ノック」版 | 約 +1.7 点 |

※ モンテカルロ法（ランダムプレイアウト）版も試しましたが、プレイアウト方策の偏りでこのヒューリスティック版より弱かったため採用していません。

## GitHub Pages で公開する

1. このブランチを `main` にマージします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. `main` への push（または Actions タブから `Deploy to GitHub Pages` を手動実行）で `web/` が公開されます。URL は `https://<ユーザー名>.github.io/gin_rummy/` です。

## ローカルで動かす

```bash
cd web && python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます（ES Modules を使うため `file://` 直開きではなくHTTPサーバー経由で）。

## 開発

```bash
node tools/test.mjs                               # ルールエンジンのテスト
node tools/selfplay.mjs 500 strong normal 1       # AI同士の対戦（ハンド数 A B seed [Aのパラメータ上書きJSON]）
node tools/selfplay.mjs 500 strong strong 1 '{"beta":6}'
```

ファイル構成:

- `web/index.html`, `web/style.css` — 画面
- `web/js/engine.js` — ルール（メルド探索、デッドウッド、付け札、得点、ハンド進行、マッチ）
- `web/js/ai.js` — AI（最強 / ふつう / よわい）
- `web/js/ui.js` — 画面の制御
- `tools/` — テストと自己対戦スクリプト
