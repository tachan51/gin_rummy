# ジンラミー vs 最強AI

ブラウザで遊べるジンラミー（Gin Rummy）。カードを数え、相手の手を読むAIと対戦できます。ビルド不要の静的サイトで、GitHub Pages で公開できます。

## 遊び方

- 山札か捨て札をタップして1枚引き、手札のカードをタップして選択 → もう一度タップ（または「捨てる」）で捨てます。
- 捨てた後のデッドウッドが10以下なら「ノック」、0なら「ジン！」。
- 「ヒント」で最強AIのおすすめ手が見られます。「設定」で AI の強さ（最強 / ふつう / よわい）・目標点・AIの手札表示（練習用）を変えられます。
- ルールの詳細はゲーム画面右上の「ルール」から確認できます。
